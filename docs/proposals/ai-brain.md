# AI 大脑升级提案：从"会打"到"会赢"

> 提案人：AI-KIMI-ENG ｜ 状态：待指挥官批准 ｜ 关联工单：Issues「AI大脑」

## 体检结论

现有 AI（26KB）骨架意外地全：占点/运输/躲避/补给/照明/自爆都有。
**缺的是"脑子"**：目标打分仅 3 处 score、零伤害预估、零威胁规避、所有兵种共用一套行为——22 个兵种用出了 3 种打法。

## 设计哲学（沿袭格战宪法）

1. **数据驱动**：AI 行为不是写死的 if-else，而是每个单位的「AI 档案」Export 字段——检查器可调、默认与原作一致
2. **不作弊**：AI 只用玩家拿得到的公开信息（伤害矩阵/视野/感知，全是 public 函数）
3. **复用优先**：伤害预估用 GetBaseDamageFromMatrix，零新数值系统

## 三层架构

- 战略层：生产优先级表（已有，扩充）+ 全局目标
- 战术层：威胁图（敌火力覆盖）+ 伤害预估 + 走位评分
- 个体层：每单位每回合决策树（角色驱动）

## AI 档案字段（Infantry 新增 ExportGroup，默认=原作行为）

| 字段 | 含义 | 战斗机 |
|---|---|---|
| aiRole | 角色：突击/火力/猎手/护送/运输/占点/支援/防空/刺客 | 防空 |
| aiTargetWeights | 目标类型→权重（空=按伤害预估） | 空军×3 地面×0 |
| aiRetreatHpThreshold | 血≤N 撤退（0=死战） | 0 |
| aiPreferKill | 优先预估能击杀的目标 | true |
| aiKiteAfterAttack | 攻击后拉开 | false |
| aiAvoidThreatRadius | 避开敌威胁半径（0=无畏） | 1 |
| aiFocusFire | 集火残血 | true |

## 阶段一：六条最高 ROI 行为

1. **兵种目标优先级**：战斗机只咬空军/轰炸机绕开防空/导弹车只打空中
2. **伤害预估进打分**：预估击杀优先，挠痒换目标
3. **残血撤退**：低于阈值往己方建筑撤（复用 AIEvade）
4. **间接火力卡射程**：火炮/火箭/导弹车走位="打得到且打不到我"
5. **运输斩首**：TCopter 装兵直飞敌 HQ/空城（教程第7关战术）
6. **隐身刺客**：Stealth 打完即隐身脱离（隐身模块首个战术用户）

## 验收

- AI 对局观察：战斗机不舔地、轰炸机不撞防空、残血会后撤
- 每个行为在 AI 档案字段里可查（检查器）
- 不作弊回归：AI 看不到迷雾外/隐身单位（现有感知过滤不破）
